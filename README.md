# Salezy — downloads

Installers for **Salezy**, the offline, keyboard-first billing and POS app for shops, pharmacies and
mini supermarkets. Website: https://zylio.net

| Platform | File | Notes |
|---|---|---|
| Windows 10 / 11 (64-bit) | `SalezySetup.exe` | Installs to Program Files; the app updates itself from this page |
| Linux (x86_64) | `Salezy-x86_64.AppImage` | `chmod +x` then run; no install needed |

Grab the newest version from the [Releases](https://github.com/faisalrasheed442/salezy-releases/releases/latest) page.
